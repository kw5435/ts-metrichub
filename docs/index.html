FAQ

Im Gegensatz zu cloudbasierten Lösungen werden die Daten nicht in einer Datenbank oder auf einem Server gespeichert, sondern ausschließlich lokal in Ihrem Browser (Web Storage/localStorage).

Das bedeutet: Nach jeder Änderung oder regelmäßig sollten Sie Ihre Daten über "Daten exportieren" im Seitenmenü als JSON-Datei sichern. Nur so sind die Daten langfristig verfügbar und gehen nicht verloren, z. B. wenn Sie den Browser-Cache leeren oder das Gerät wechseln.

Diese App ist primär eine Webseite zur Datenerfassung und Auswertung – Ihre gesicherten JSON-Dateien sind die eigentliche Datenquelle. Über "Daten importieren" können Sie jederzeit einen vorherigen Sicherungsstand wiederherstellen.
KPIs (Key Performance Indicators) sind messbare Werte, die den Erfolg eines Mitarbeiters oder Teams darstellen.
Gehen Sie auf "KPI erfassen", wählen Sie einen Mitarbeiter und KPI, geben Sie den Wert ein und klicken Sie auf "Erfassen".
Gehen Sie auf "Mitarbeiter verwalten" und bearbeiten Sie beim jeweiligen Mitarbeiter die KPIs und Jahresziele direkt in der Tabellenansicht.
Pro KPI wählen Sie zwischen Stk. (Stück), € (Euro) oder % (Prozent). Die Einheit wird bei Änderung automatisch für alle Mitarbeiter mit gleichem KPI-Namen synchronisiert.
Gehen Sie auf "Mitarbeiter verwalten" und klicken Sie auf "+ Mitarbeiter hinzufügen". Im Wizard können Sie Name, Zeitraum und bestehende KPIs übernehmen.
Unter "Mitarbeiter verwalten" finden Sie die Schaltflächen "Deaktivieren" und "Löschen" in jeder Mitarbeiter-Karte. Deaktivierte Mitarbeiter können Sie auch wieder reaktivieren.
Das Dashboard zeigt Gesamtziel, Erfüllungsgrad, Top-5-Rangliste, eine Übersicht aller Mitarbeiter als Tabelle und einen Linienchart mit dem KPI-Verlauf der letzten 8 Monate.
Hier können Sie einen einzelnen Mitarbeiter auswählen und dessen KPI-Zielerreichung im Detail sehen – inkl. Verlauf, Differenzen und einem eigenen Chart. Die Ansicht "Alle" zeigt eine Rangliste aller aktiven Mitarbeiter.
Im Dashboard und im Mitarbeiter-Dashboard gibt es ein "KPI"-Dropdown. Damit wählen Sie, welcher KPI in den Kennzahlen und Ranglisten angezeigt wird.
Klicken Sie im Dashboard auf "Aushang drucken". Es wird eine druckoptimierte Ansicht im A4-Format generiert – pro Mitarbeiter eine Übersicht mit allen Monatswerten, Zielen und Abweichungen.
Nutzen Sie "CSV Export" im Dashboard für eine CSV-Datei oder "Daten exportieren" im Seitenmenü für einen kompletten JSON-Backup.
Klicken Sie im Seitenmenü auf "Daten importieren" und wählen Sie eine zuvor exportierte JSON-Datei aus. Bestehende Daten werden dabei ersetzt.
Alle Daten werden lokal im Browser (localStorage) gespeichert. Es wird kein Server benötigt. Sichern Sie Ihre Daten regelmäßig über "Daten exportieren".
In den Einstellungen können Sie Demo-Daten laden – Variante 1 (ganzes Jahr) oder Variante 2 (Januar–Juni). Damit können Sie die App sofort testen.
Gehen Sie zu "Einstellungen" und wählen Sie das gewünschte Jahr aus. Die Monatsauswahl in den Dashboards passt sich automatisch an.
Standard können Sie mehrere KPIs pro Mitarbeiter erfassen. Im Modus "Nur Umsatz" wird nur der KPI "Umsatz" verwendet – einfacher und übersichtlicher.
Ja. Unter "Einstellungen" können Sie zwischen "Hell" und "Dunkel" wechseln. Die Einstellung wird gespeichert und auf alle Seiten übernommen.
